# 低换手组合：机构版与个人版回测

## 1. 实验目的

本实验固定使用 `artifacts/csi800_pit_walk_forward/walk_forward_predictions.csv` 中已经生成的
样本外 XGBoost 分数，只重跑组合构建与逐日成交模拟。这样可以把结果变化明确归因于低换手规则，
而不是重新训练模型或选择一次更有利的随机结果。

回测区间为 2019-08-01 至 2026-09-04，共 1,722 个交易日、85 次月度调仓。2019 年与
2026 年均为不完整年度。数据证据等级仍为 `LIMITED_RESEARCH`：免费数据提供历史时点中证
300/500 成分股，但无法完整提供逐日历史 ST/状态字段。

## 2. 低换手规则

两套组合都保留月频信号与下一交易日开盘成交，不引入日内交易、LLM 打分或人工择时。

| 规则 | 机构版 | 个人版 |
|---|---:|---:|
| 初始资金 | 5,000,000 元 | 300,000 元 |
| 目标持股数 | 50 | 5 |
| 新股准入排名 | 前 50 | 前 5 |
| 旧股退出缓冲 | 跌出前 100 | 跌出前 12 |
| 常规每月最多替换 | 10 | 1 |
| 新旧股票最小排名差 | 10 | 5 |
| 权重免调仓带 | ±0.5% | ±3.0% |
| 最低非清仓交易金额 | 5,000 元 | 2,000 元 |
| 目标现金 | 2% | 2% |

“最多替换”约束针对常规的排名驱动替换。停牌、涨跌停、股票不再可交易、整数手、现金不足和
成交量上限可能使实际持仓暂时偏离目标；系统不会为了满足数量约束而假设一笔现实中无法成交的
订单。

## 3. 总体结果

| 指标 | 机构版 | 个人版 |
|---|---:|---:|
| 期末资产 | 7,684,182 元 | 463,267 元 |
| 累计收益 | 53.68% | 54.42% |
| 年化收益 | 6.49% | 6.57% |
| 年化波动 | 17.40% | 20.28% |
| Sharpe | 0.448 | 0.415 |
| 最大回撤 | -21.84% | -44.16% |
| 月均双边换手 | 45.70% | 44.49% |
| 成交订单 | 2,092 | 236 |
| 被拒订单 | 224 | 48 |
| 总费用 | 127,923.44 元 | 7,854.12 元 |
| 费用 / 初始资金 | 2.56% | 2.62% |

原始 50 股方案的月均双边换手为 136.24%，费用占初始资金 7.83%。机构低换手版分别下降
约66%和67%；个人版也下降约67%和67%。

## 4. 基准比较

| 基准 | 基准累计收益 | 机构版相对差 | 个人版相对差 |
|---|---:|---:|---:|
| 沪深300 | 18.58% | +35.10% | +35.84% |
| 上证综指 | 34.02% | +19.66% | +20.40% |
| 深证成指 | 44.93% | +8.75% | +9.49% |
| 中证500 | 56.08% | -2.39% | -1.65% |
| 历史时点中证800等权股票池 | 65.49% | -11.81% | -11.07% |

因此，不能把结果描述成“跑赢所有基准”。两套方案都跑赢了更符合大众展示习惯的沪深300、
上证综指和深证成指，但没有跑赢中证500及历史时点股票池等权组合。后两者必须继续保留为
研究诊断基准，防止只挑容易战胜的指数。

## 6. 结论

机构版是更适合作为券商科技项目主报告的组合：它在大幅降低换手后，累计收益为53.68%，
最大回撤控制在-21.84%，风险分散也更符合机构组合逻辑。

个人版证明同一个研究平台可以接受不同资金量和持仓数量，但5股集中组合最大回撤达到
-44.16%，说明“少持股”不是免费的收益增强，而是显著增加个股路径风险。它适合作为产品化
能力演示，不应被包装成比机构版更稳健的策略。

完整机器可读结果位于 `artifacts/low_turnover/`；可使用
`python scripts/run_low_turnover_scenarios.py` 在固定样本外预测上复现。

注：本页数值已在确定性订单排序修复后重新生成；同一配置已通过独立进程复跑一致性检查。
