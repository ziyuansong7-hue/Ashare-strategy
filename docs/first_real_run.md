# 首次完整真实数据运行报告

> 历史阶段文档：本页记录 V1 低换手规则实施前的高换手基线，用于说明问题如何被发现。当前冻结结果请以[低换手回测](low_turnover_backtest.md)与[正式验证报告](formal_strategy_validation.md)为准。

## 结论摘要

本次使用零付费数据路径，完成了历史时点中证800股票池、日线下载、公司行为、外部基准、因子计算、扩展窗口 walk-forward、XGBoost 横截面排序和逐日交易账本。

这不是一个“跑赢所有基准”的完美回测。XGBoost 跑赢了沪深300、中证800、上证综指和深证成指，但略低于中证500，也低于时点股票池等权基准。这表明模型有一定非线性选股信号，但还没有证明能稳定超过中盘风格和等权收益。

## 回测设置

- 月末产生信号，下一个交易日开盘执行。
- 目标是 T+1 开盘至 T+20 收盘的横截面超额收益排名。
- 36 个月起始训练、12 个月验证、12 个月测试，扩展窗口。
- 7 个完整年度测试折 + 1 个只含一个调仓日的末尾折。
- 组合默认持有 50 只，等权，跌出前 70 名后退出。
- 最低 20% 流动性股票被排除，调仓时每期至少 200 只候选股。
- 考虑 100 股手数、佣金、最低佣金、卖出印花税、过户费、滑点、成交量参与率和现金余额。

XGBoost 相对线性因子组合增加了 21.62 个百分点的累计收益，同时将最大回撤缩小约 20.86 个百分点。这支持“非线性交互有增量信息”，但不等于证明产品级 Alpha。

## 模型稳定性

- 前 7 个完整年度折中，XGBoost 有 6 折的平均 RankIC 为正，7 折平均 RankIC 为 0.0476。
- 最后的不完整折只有 2026-07-31 一个调仓截面，RankIC 为 -0.3526；单点不具有统计代表性，但是必须如实保留的负面证据。
- LARGE 组的全期平均 RankIC 为 0.0402，MID 组为 0.0458，信号不完全依赖某一个市值分组。

## 已发现的问题

1. XGBoost 仍未跑赢时点股票池等权，也没有跑赢中证500。
2. XGBoost 平均单次调仓换手约 136.24%，全期交易费用约 78,315 元（初始资金 100 万元），换手偏高。
3. 6,496 笔订单成交，782 笔因交易限制被拒绝；模拟已比“理想排名收益”更保守，但仍不是交易所级撮合。
4. 免费版没有完整的逐日历史 ST/停牌库，不能把本次收益表述为无偏正式业绩。
5. 本次只验证了默认 50 只组合；3–5 只个人组合的集中度、手数可行性和回撤会明显不同，需要单独做敏感性测试。
